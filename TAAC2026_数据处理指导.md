## 二、列结构详解（120 列分 6 类）

```
120 列
├── ID & Label          5 列   (int64/int32)
├── User Int Features  46 列   (int64 / list<int64>)
├── User Dense Features 10 列  (list<float>)
├── Item Int Features  14 列   (int64 / list<int64>)
├── Domain Sequence Features 45 列  (list<int64>)
└── [Context 特征已融合在上述各类中]
```

---

### 2.1 ID & Label（5 列，无 null）

| 列名 | 类型 | 含义 |
|-----|------|------|
| `user_id` | int64 | 用户 ID（匿名） |
| `item_id` | int64 | 目标广告/物品 ID（匿名） |
| `label_type` | int32 | **标签**：转化行为类型（需确认是否直接用作 0/1） |
| `label_time` | int64 | 标签发生时间戳（Unix 秒） |
| `timestamp` | int64 | 请求时间戳（曝光时刻，Unix 秒） |

> **注**：`label_time` 与 `timestamp` 的差值可作为时间窗口特征；`timestamp` 是行为序列截断的时间基准点。

---

### 2.2 User Int Features（46 列）

| 子类型 | 列名规律 | 列数 | PyTorch 类型 |
|-------|---------|------|-------------|
| Scalar | `user_int_feats_{1,3,4,48-59,82,86,92-109}` | 35 列 | `LongTensor` |
| Array | `user_int_feats_{15,60,62-66,80,89-91}` | 11 列 | `LongTensor` (padding后) |

**处理要点**：
- Scalar：直接 Embedding Lookup
- Array：多值特征，做 **Embedding + Mean Pooling**（或 Max Pooling）
- 存在 `null` 值，用 `0` 填充（保留 ID=0 作为 PAD/UNK token）

---

### 2.3 User Dense Features（10 列）

| 列名规律 | 列数 | PyTorch 类型 |
|---------|------|-------------|
| `user_dense_feats_{61-66,87,89-91}` | 10 列 | `FloatTensor` |

**关键注意**：  
> `user_int_feats_{fid}` 和 `user_dense_feats_{fid}` 若 **fid 相同**，则它们描述同一个实体/信号——整数 ID 版本和稠密向量版本是对齐的（如 fid=61~66, 89-91）。

**处理要点**：
- 每列是 `list<float>`，长度固定（需确认维度）
- 直接转为 `FloatTensor`，接一个线性投影层对齐维度
- 可做 z-score 归一化（基于训练集统计）

---

### 2.4 Item Int Features（14 列）

| 子类型 | 列名规律 | 列数 | PyTorch 类型 |
|-------|---------|------|-------------|
| Scalar | `item_int_feats_{5-10,12-13,16,81,83-85}` | 13 列 | `LongTensor` |
| Array | `item_int_feats_{11}` | 1 列 | `LongTensor` (padding后) |

**处理要点**：同 User Int Features，Embedding Lookup + 可选 MLP 投影

---

### 2.5 Domain Sequence Features（45 列）⭐ 核心

来自 **4 个行为域（domain）** 的用户历史交互序列，每列是 `list<int64>`：

| 域 | 列名规律 | 列数 | 语义 |
|----|---------|------|-----|
| Domain A | `domain_a_seq_{38-46}` | 9 列 | 行为域 A 的多维序列（item/action/time等） |
| Domain B | `domain_b_seq_{67-79,88}` | 14 列 | 行为域 B |
| Domain C | `domain_c_seq_{27-37,47}` | 12 列 | 行为域 C |
| Domain D | `domain_d_seq_{17-26}` | 10 列 | 行为域 D |

**理解方式**：每个 domain 的多列共同描述一条序列的多个属性，例如：
```
domain_a_seq_38 = [item_id_1, item_id_2, ...]   # item id 序列
domain_a_seq_39 = [action_1, action_2, ...]      # action type 序列  
domain_a_seq_40 = [timestamp_1, timestamp_2, ...]# 时间戳序列
...（各列意义需通过 EDA 推断，官方未明示语义）
```

**处理要点**：
- 同一 domain 的多列**按位置对齐**，构成 `(seq_len, num_features)` 的序列矩阵
- 序列长度不等，需要 padding 和 masking
- 时间戳列可用于计算时间差特征（`timestamp - seq_time`）

### 4.2 User Int Scalar Features（35列 → Embedding）

```python
import torch
import torch.nn as nn

class UserIntScalarEmbedding(nn.Module):
    """为每个 scalar int 特征学习独立的 embedding"""
    
    def __init__(self, vocab_sizes: dict, embed_dim: int = 32):
        """
        vocab_sizes: {col_name: cardinality}
        cardinality 通过 EDA 统计（train 集最大值 + 1 + UNK）
        """
        super().__init__()
        self.embeddings = nn.ModuleDict({
            col: nn.Embedding(vocab_size + 2, embed_dim, padding_idx=0)
            # +2: 0=PAD/NULL, vocab_size+1=UNK（处理 OOV）
            for col, vocab_size in vocab_sizes.items()
        })
    
    def forward(self, x: dict) -> torch.Tensor:
        """
        x: {col_name: LongTensor(batch_size,)}
        return: FloatTensor(batch_size, num_cols * embed_dim)
        """
        embeds = [self.embeddings[col](x[col]) for col in x]
        return torch.cat(embeds, dim=-1)


def preprocess_int_scalar(df: pd.DataFrame, cols: list) -> pd.DataFrame:
    """null 填 0（作为 PAD），clip 超出范围的值"""
    for col in cols:
        df[col] = df[col].fillna(0).astype(int)
    return df
```

### 4.3 User Int Array Features（11列 → Multi-hot Embedding）

```python
def pad_int_array(seq: list, max_len: int, pad_val: int = 0) -> list:
    """截断并右填充"""
    if seq is None:
        return [pad_val] * max_len
    seq = [x if x is not None else pad_val for x in seq]
    if len(seq) >= max_len:
        return seq[:max_len]
    return seq + [pad_val] * (max_len - len(seq))


class MultiValueEmbedding(nn.Module):
    """多值 int 特征：Embedding + Mean Pooling"""
    
    def __init__(self, vocab_size: int, embed_dim: int, max_len: int = 20):
        super().__init__()
        self.embed = nn.Embedding(vocab_size + 2, embed_dim, padding_idx=0)
        self.max_len = max_len
    
    def forward(self, x: torch.LongTensor) -> torch.Tensor:
        """
        x: (batch_size, max_len)
        return: (batch_size, embed_dim)
        """
        mask = (x != 0).float().unsqueeze(-1)   # (B, L, 1)
        emb = self.embed(x)                      # (B, L, D)
        summed = (emb * mask).sum(dim=1)         # (B, D)
        count = mask.sum(dim=1).clamp(min=1)     # (B, 1)
        return summed / count                    # Mean Pooling
```

### 4.4 User Dense Features（10列 → 归一化 + MLP 投影）

```python
from sklearn.preprocessing import StandardScaler

def preprocess_dense_features(
    train_df: pd.DataFrame, 
    test_df: pd.DataFrame,
    cols: list
) -> tuple:
    """
    每列是 list<float>，先 explode 后 fit_transform，再 reshape 回来
    注意：只用训练集 fit，测试集 transform
    """
    # 将 list 列展开为矩阵
    def extract_matrix(df, cols):
        return np.stack([
            np.array(df[col].apply(
                lambda x: x if x is not None else [0.0] * len(x)
            ).tolist())
            for col in cols
        ], axis=1)   # (N, num_dense_cols, vector_dim) -- 需确认每列的 list 长度
    
    # 如果每列是标量 float list（如 [0.111, 0.057, ...]）
    # 则拼接后 shape = (N, total_dense_dim)
    def flatten_dense(df, cols):
        arrays = []
        for col in cols:
            col_data = df[col].apply(
                lambda x: x if isinstance(x, list) else [0.0]
            )
            arrays.append(np.array(col_data.tolist()))
        return np.concatenate(arrays, axis=1)   # (N, sum_of_all_dims)
    
    train_mat = flatten_dense(train_df, cols)
    test_mat = flatten_dense(test_df, cols)
    
    scaler = StandardScaler()
    train_mat = scaler.fit_transform(train_mat)
    test_mat = scaler.transform(test_mat)
    
    return train_mat, test_mat, scaler
```

### 4.5 ⭐ Domain Sequence Features（45列 → 序列构建 + Padding）

这是数据处理最复杂也最重要的部分。

```python
def build_domain_sequence(
    row: pd.Series,
    domain_cols: list,
    max_seq_len: int = 100,
    pad_val: int = 0
) -> torch.LongTensor:
    """
    将一个 domain 的多列序列整合为 (max_seq_len, num_features) 矩阵
    
    Args:
        row: 一行 DataFrame 数据
        domain_cols: 该 domain 的所有列名，如 DOMAIN_A_COLS
        max_seq_len: 序列最大长度（截断策略：取最近 N 个）
        pad_val: padding 值（0）
    
    Returns:
        LongTensor: (max_seq_len, num_features)
        mask: BoolTensor: (max_seq_len,) True=有效位置
    """
    # 取出各列的 list，确定真实序列长度
    cols_data = []
    seq_len = 0
    for col in domain_cols:
        val = row[col]
        if val is None or (isinstance(val, float) and np.isnan(val)):
            val = []
        cols_data.append(list(val))
        seq_len = max(seq_len, len(val))
    
    if seq_len == 0:
        # 整个 domain 序列为空
        seq_mat = torch.zeros(max_seq_len, len(domain_cols), dtype=torch.long)
        mask = torch.zeros(max_seq_len, dtype=torch.bool)
        return seq_mat, mask
    
    # 截断：取最近 max_seq_len 个（从末尾取，即最新行为）
    start = max(0, seq_len - max_seq_len)
    effective_len = min(seq_len, max_seq_len)
    
    seq_mat = []
    for col_data in cols_data:
        col_slice = col_data[start:]                         # 截断
        # padding 到 max_seq_len（右填充）
        pad_needed = max_seq_len - len(col_slice)
        col_padded = col_slice + [pad_val] * pad_needed
        # None 值填 pad_val
        col_padded = [x if x is not None else pad_val for x in col_padded]
        seq_mat.append(col_padded)
    
    seq_tensor = torch.tensor(seq_mat, dtype=torch.long).T  # (max_seq_len, num_features)
    
    mask = torch.zeros(max_seq_len, dtype=torch.bool)
    mask[:effective_len] = True
    
    return seq_tensor, mask


def add_time_decay_feature(
    seq_timestamps: list,
    current_timestamp: int,
    max_seq_len: int = 100
) -> torch.FloatTensor:
    """
    计算序列中每个行为到当前时间的时间差（秒），
    可作为额外的序列位置特征输入模型
    """
    if not seq_timestamps:
        return torch.zeros(max_seq_len)
    
    # 截断到最近 max_seq_len
    seq_ts = seq_timestamps[-max_seq_len:]
    time_deltas = [max(0, current_timestamp - ts) for ts in seq_ts]
    
    # 归一化：log1p 压缩大值
    time_deltas = np.log1p(time_deltas)
    
    # padding
    pad_needed = max_seq_len - len(time_deltas)
    time_deltas = time_deltas + [0.0] * pad_needed
    
    return torch.tensor(time_deltas, dtype=torch.float)
```

## 五、PyTorch Dataset 实现

```python
# src/data/dataset.py

import torch
from torch.utils.data import Dataset
import pandas as pd
import numpy as np
from .schema import (
    USER_INT_SCALAR_COLS, USER_INT_ARRAY_COLS, USER_DENSE_COLS,
    ITEM_INT_SCALAR_COLS, ITEM_INT_ARRAY_COLS, ALL_SEQ_DOMAINS
)


class TAAC2026Dataset(Dataset):
    """
    TAAC2026 竞赛数据集
    
    每条样本返回：
    {
        "user_int_scalar":  LongTensor (35,)
        "user_int_arrays":  {col: LongTensor (max_array_len,)}
        "user_dense":       FloatTensor (total_dense_dim,)
        "item_int_scalar":  LongTensor (13,)
        "item_int_array":   LongTensor (max_array_len,)
        "seq_domain_a":     LongTensor (max_seq_len, 9)
        "seq_domain_a_mask":BoolTensor  (max_seq_len,)
        "seq_domain_b":     LongTensor (max_seq_len, 14)
        "seq_domain_b_mask":BoolTensor  (max_seq_len,)
        "seq_domain_c":     LongTensor (max_seq_len, 12)
        "seq_domain_c_mask":BoolTensor  (max_seq_len,)
        "seq_domain_d":     LongTensor (max_seq_len, 10)
        "seq_domain_d_mask":BoolTensor  (max_seq_len,)
        "label":            FloatTensor scalar
        "timestamp":        LongTensor scalar
    }
    """
    
    def __init__(
        self,
        df: pd.DataFrame,
        max_seq_len: int = 100,
        max_array_len: int = 20,
        dense_mean: np.ndarray = None,   # 训练集均值，用于归一化
        dense_std: np.ndarray = None,    # 训练集标准差
        is_train: bool = True,
    ):
        self.df = df.reset_index(drop=True)
        self.max_seq_len = max_seq_len
        self.max_array_len = max_array_len
        self.dense_mean = dense_mean
        self.dense_std = dense_std
        self.is_train = is_train
        
        # 预处理：null 填充
        self._preprocess_nulls()
    
    def _preprocess_nulls(self):
        """统一处理缺失值"""
        # Scalar int: null -> 0
        for col in USER_INT_SCALAR_COLS + ITEM_INT_SCALAR_COLS:
            if col in self.df.columns:
                self.df[col] = self.df[col].fillna(0).astype(np.int64)
        
        # Array int: null -> []
        for col in USER_INT_ARRAY_COLS + ITEM_INT_ARRAY_COLS:
            if col in self.df.columns:
                self.df[col] = self.df[col].apply(
                    lambda x: x if isinstance(x, list) else []
                )
        
        # Sequence: null -> []
        for domain_cols in ALL_SEQ_DOMAINS.values():
            for col in domain_cols:
                if col in self.df.columns:
                    self.df[col] = self.df[col].apply(
                        lambda x: x if isinstance(x, list) else []
                    )
    
    def __len__(self):
        return len(self.df)
    
    def __getitem__(self, idx: int) -> dict:
        row = self.df.iloc[idx]
        sample = {}
        
        # ── 1. User Int Scalar ──────────────────────────────
        user_int_scalar = torch.tensor(
            [int(row.get(col, 0)) for col in USER_INT_SCALAR_COLS],
            dtype=torch.long
        )
        sample["user_int_scalar"] = user_int_scalar  # (35,)
        
        # ── 2. User Int Array ───────────────────────────────
        user_int_arrays = {}
        for col in USER_INT_ARRAY_COLS:
            arr = row.get(col, [])
            arr = [int(x) if x is not None else 0 for x in arr]
            if len(arr) > self.max_array_len:
                arr = arr[:self.max_array_len]
            arr = arr + [0] * (self.max_array_len - len(arr))
            user_int_arrays[col] = torch.tensor(arr, dtype=torch.long)
        sample["user_int_arrays"] = user_int_arrays
        
        # ── 3. User Dense ────────────────────────────────────
        dense_vals = []
        for col in USER_DENSE_COLS:
            v = row.get(col, None)
            if isinstance(v, list):
                dense_vals.extend([float(x) if x is not None else 0.0 for x in v])
            else:
                dense_vals.append(float(v) if v is not None else 0.0)
        dense_arr = np.array(dense_vals, dtype=np.float32)
        if self.dense_mean is not None and self.dense_std is not None:
            dense_arr = (dense_arr - self.dense_mean) / (self.dense_std + 1e-8)
        sample["user_dense"] = torch.tensor(dense_arr, dtype=torch.float)
        
        # ── 4. Item Int Scalar ──────────────────────────────
        item_int_scalar = torch.tensor(
            [int(row.get(col, 0)) for col in ITEM_INT_SCALAR_COLS],
            dtype=torch.long
        )
        sample["item_int_scalar"] = item_int_scalar  # (13,)
        
        # ── 5. Item Int Array ───────────────────────────────
        for col in ITEM_INT_ARRAY_COLS:
            arr = row.get(col, [])
            arr = [int(x) if x is not None else 0 for x in arr]
            if len(arr) > self.max_array_len:
                arr = arr[:self.max_array_len]
            arr = arr + [0] * (self.max_array_len - len(arr))
            sample["item_int_array"] = torch.tensor(arr, dtype=torch.long)
        
        # ── 6. Domain Sequences ──────────────────────────────
        current_ts = int(row.get("timestamp", 0))
        for domain_name, domain_cols in ALL_SEQ_DOMAINS.items():
            seq_tensor, mask = build_domain_sequence(
                row, domain_cols, self.max_seq_len
            )
            sample[f"seq_{domain_name}"] = seq_tensor          # (max_seq_len, F)
            sample[f"seq_{domain_name}_mask"] = mask           # (max_seq_len,)
        
        # ── 7. Label ─────────────────────────────────────────
        if self.is_train:
            label_type = int(row.get("label_type", 0))
            # ⚠️ 待 EDA 确认：是否 label_type > 0 即为正样本
            sample["label"] = torch.tensor(float(label_type > 0), dtype=torch.float)
        
        sample["timestamp"] = torch.tensor(current_ts, dtype=torch.long)
        
        return sample
```

```python
# scripts/preprocess.py

import pandas as pd
import numpy as np
from torch.utils.data import DataLoader, random_split
from src.data.dataset import TAAC2026Dataset

def build_dataloaders(
    parquet_path: str,
    val_ratio: float = 0.1,
    batch_size: int = 1024,
    max_seq_len: int = 100,
    num_workers: int = 4,
    seed: int = 42,
):

    df = df.sort_values("timestamp").reset_index(drop=True)

    def extract_dense_matrix(df):
        arrays = []
        for col in USER_DENSE_COLS:
            col_data = df[col].apply(
                lambda x: x if isinstance(x, list) else [0.0]
            )
            arrays.append(np.array(col_data.tolist()))
        return np.concatenate(arrays, axis=1).astype(np.float32)
    
    train_dense = extract_dense_matrix(train_df)
    dense_mean = train_dense.mean(axis=0)
    dense_std = train_dense.std(axis=0)
    
    # ── 构建 Dataset ──
    train_dataset = TAAC2026Dataset(
        train_df, max_seq_len=max_seq_len,
        dense_mean=dense_mean, dense_std=dense_std,
        is_train=True
    )
    val_dataset = TAAC2026Dataset(
        val_df, max_seq_len=max_seq_len,
        dense_mean=dense_mean, dense_std=dense_std,
        is_train=True
    )
    
    train_loader = DataLoader(
        train_dataset,
        batch_size=batch_size,
        shuffle=True,
        num_workers=num_workers,
        pin_memory=True,
        drop_last=True,
    )
    val_loader = DataLoader(
        val_dataset,
        batch_size=batch_size * 2,
        shuffle=False,
        num_workers=num_workers,
        pin_memory=True,
    )
    
    return train_loader, val_loader, {"dense_mean": dense_mean, "dense_std": dense_std}
```

## 九、常见坑

| 坑 | 症状 | 解决方案 |
|----|------|---------|
| list<int64> 列读为 `object` 类型 | `df[col].dtype == object` | 正常的，用 `.apply(list)` 处理 |
| 序列列有 `NaN`（不是空列表） | `isinstance(x, float) and np.isnan(x)` 为 True | 统一用 `x if isinstance(x, list) else []` 处理 |
| Int 列有 `null` 转为 float | `col.dtype == float64`（因为有 null） | `fillna(0).astype(int)` |
| 同一 domain 不同列长度不一致 | 序列对齐失败 | 取各列 `min(len)` 作为有效长度 |
| Dense 特征 list 长度不固定 | 拼接维度不对 | EDA 先确认每列 list 的固定长度 |
| 测试集有训练集未见的 ID（OOV） | Embedding 越界 | vocab_size 用 `max_val + 2`，`clamp(0, vocab_size-1)` |
